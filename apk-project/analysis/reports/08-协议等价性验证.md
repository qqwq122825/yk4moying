## 4. 那 27 处差异到底是什么

全部是同一类：原包 smali 把 R8 写进 DEX 的静态字段初值带了出来，重建包再反编译时省略。

```diff
-.field private static final DEBUG:Z = false
+.field private static final DEBUG:Z
-.field public static ء:I = 0x0
+.field public static ء:I
-.field public static volatile ض:Lڜٟٱڀ/د; = null
+.field public static volatile ض:Lڜٟٱڀ/د;
```

`static` 字段在类初始化前本来就是 `false / null / 0`，显式写与不写在 JVM/Dalvik 语义上完全等价，
既不改指令流，也不改常量池引用。协议包内属于这一类的 5 个文件：

```
ڝږ؁ڋ/أ.smali   ڝږ؁ڋ/ؼ.smali   ڝږ؁ڋ/و.smali   ڗًقڔ/ء.smali   ڜٟٱڀ/د.smali
```

其余 22 个都在 androidx / 业务 service 里（同样只是 `= false` / `= null` 被省略）。

## 6. 一句话回答

重建包与原包**同协议、同指令表、同帧格式、同分片约定、同加解密**；注入包因为直接沿用模板 DEX，
`classes.dex` 与原包逐字节相同，协议面零改动。差异只剩静态字段默认值的书写形式（27 个文件，等价）。
