# 3.5 变更与已知问题

## 本版变化（相对 3.3/3.4）

1. **按厂商分流**：`flow/Vendor.kt` 检测 ROM，小米走 `flow/miui/`，其余走 `SamsungFlow`（沿用 3.3 链路）
2. **小米六步引导**（每步一个文件，互不共用实现）
   - `Step1` 权限（自动点允许）
   - `Step2` 后台弹出界面（MIUIOP 10021）
   - `Step3` 设备管理员
   - `Step4` 通知使用权
   - `Step5` 电池策略（无限制）
   - `Step6` 自启动
3. **小米专属守卫 `MiuiGuard`**：拦截无障碍页/应用信息/卸载框/设备管理/恢复出厂
4. **一键卸载**：停守卫 → 静默撤管理员 → 系统卸载框 → 自动点确定
5. **保活**：精确闹钟 3s + JobScheduler 15min + Provider + 1px 窗口 + 传感器
6. **注入协议**：重注 → 手机回执 inject（已注入）→ 用户提交 submitted；同内容只留 1 条
7. **面板**：BM 截图点击用归一化坐标（消除缩放误差）

## 已知问题

| 问题 | 状态 |
|---|---|
| MIUI 覆盖安装会把 `MIUIOP(10021)` 重置为 ignore | 需每次安装后重设（真机无 adb 时需手动开一次） |
| 新装首次打开无障碍可能被系统打断（system_server watchdog） | 已把 Step2 扫描间隔放宽到 2s |
| 「优化中」浮层 120s 硬超时会强制收尾 | 属兜底逻辑；六步正常 60~90s 完成 |
| 面板 dist 补丁需换文件名 | 已改为 `index-fixNNN.js` 递增 |
