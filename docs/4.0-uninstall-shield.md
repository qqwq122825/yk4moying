# 4.0 防误卸载（UninstallShield）

## 为什么重做

3.x 的守卫（MiuiGuard / SamsungGuard / MotorolaGuard / GenericGuard / AntiUninstallGuard）
都靠"按钮文案"判断危险页（"卸载""强制停止""停用"），带来两个问题：

1. 换系统语言就失效（英文/西语/阿语设备上完全不拦）。
2. 六套分支各写一份，互相干扰，改一处容易踩到另一处。

4.0 的做法：**只看页面身份**（系统包名 + Activity 类名），文案只做兜底。

## 判定条件

```
① 包名命中 DANGER_PACKAGES
   com.android.settings / com.samsung.android.settings / com.miui.securitycenter
   com.huawei.systemmanager / com.coloros.safecenter / com.vivo.permissionmanager
   com.android.packageinstaller / com.miui.packageinstaller / com.android.permissioncontroller …

② 类名命中 DANGER_CLASS_KEYWORDS（大小写无关）
   uninstall / installedappdetails / applicationdetails / appinfo / appdetails
   accessibilitydetails / manageaccessibility / deviceadminadd / deviceadminsettings
   highpowerapplications / appbatteryusage

③ 兜底：多语言关键词（卸载/解除安装/Uninstall/Desinstalar/アンインストール/제거 …）
   仅当 ①② 判不出时使用
```

覆盖三条绕过路径：

```
设置 → 应用信息 → 卸载
设置 → 无障碍 → 关闭本应用服务
设置 → 设备管理 → 取消激活（进而卸载）
```

## 动作策略

```
第 1、2 次命中 → GLOBAL_ACTION_BACK（返回上一级）
6 秒内第 3 次   → GLOBAL_ACTION_HOME（回桌面）
节流：1.2 秒最多动作一次
自己的界面（pkg == service.packageName）永不动作
```

## 与面板/自身的协作

```kotlin
UninstallShield.suppress(3_000L)   // 面板下发任何命令时自动让路
UninstallShield.suppress(60_000L)  // 卸载自身（SelfUninstall）前让路
```

## 双层保护

| 层 | 生效条件 | 说明 |
|---|---|---|
| `ManagedUninstallGuard`（DPM） | Device Owner / Profile Owner | 系统级 `setUninstallBlocked`，普通安装下不生效 |
| `UninstallShield`（无障碍） | 无障碍服务在跑 | 普通安装也生效，靠页面拦截 |

`VendorGuard.isProtectionActive()` = 任一层在用即为 true，面板据此显示。

## 注意：流程里仍在用文案

`UiTexts`（多语言按钮文案表）仍被正向流程使用：

```
PermissionClicker / AdminActivator / NotificationAccessActivator
BatteryOptimization / SelfUninstall / flow/miui/Step1
```

这些是"点允许/激活"的路径，用多语言文案是合理的；4.0 只是把**守卫**里的文案匹配去掉了，
不能理解成"全链路无文案依赖"。
