### 结构性结论（下一版还要记住）

1. **dex 没有 `Exceptions` 属性**：jadx 给实现类加的 `throws` 全是推断，父类型没有 → 一律在实现侧用 `sneakyThrow` 或就地 `try/catch`，**不要往接口加 throws**（会连锁要求所有调用点）。
2. **错误数会被单文件放大**：一个坏文件能带出上千条连锁错误；按文件修，不按条数修。
3. **`jar + 源码` 混用时同一 FQN 只能存在一份**，否则 javac 会按 `-Xprefer:newer` 抖动，同一文件两次编译错误数不同。
